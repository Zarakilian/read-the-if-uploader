Read the If uploader

Privacy policy

Effective 18 October 2026. This policy covers the Read the If uploader, a desktop tool operated for the owner of the Read the If YouTube channel. Contact: readtheif@gmail.com.

Google data accessed

The tool uses Google OAuth to request the YouTube upload and YouTube read-only scopes. It receives access and refresh tokens and reads the authenticated channel's permanent ID and title to verify the intended channel. The read-only permission can permit access to other YouTube account information, but the current connection helper requests only the channel identity. The tool does not request access to Gmail, Drive, Contacts, payment information or the Google account password.

Purpose and use

Google data is used to connect and verify the owner's channel and support owner-directed video uploads and scheduling. The local upload workflow has been implemented and verified with an owner-authorized live upload. It sends selected video files, titles, descriptions, tags, audience declarations and publication settings to YouTube only for owner-authorized tasks. Read-only checks may inspect the owner's resulting video and processing status to confirm those tasks.

Storage and protection

Client configuration and OAuth tokens are encrypted together using Windows CurrentUser Data Protection API on the owner's PC. Channel identifiers and nonsecret task receipts may be kept in local project records. Tokens and client secrets are not intentionally printed into chat, application logs or public repositories. Code running as the same Windows user can decrypt the credential store; this is not protection from a compromised Windows account.

Sharing

Credentials are used with Google's OAuth and YouTube endpoints. Selected media and metadata are transmitted to YouTube for authorized uploads. The local workflow may be operated through the owner's AI-assisted coding application, where channel information, selected content and nonsecret task results may be visible to that application and its providers under the owner's settings. Tokens are handled internally by the local helper rather than sent as chat content. This tool does not sell Google user data, use it for advertising, or use it to develop or train generalized AI or machine-learning models.

Read the If uploader's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The local credential is retained until the owner removes it or replaces the connection. The owner can revoke access in Google Account connections and remove the local encrypted credential file. Revocation does not delete videos already uploaded to YouTube. Those videos and other Google-held data can be managed through YouTube and the owner's Google account. Local production files and nonsecret receipts are retained under the owner's project settings and can be removed by the owner.

This information website

This static site has no login, credential form, analytics script, advertising or application database. GitHub Pages hosts the site and may process ordinary request information under GitHub's privacy statement. Google and YouTube process data under their own policies.

Changes and contact

This policy will be updated when the tool's data practices change. Questions and deletion requests can be sent to readtheif@gmail.com.
